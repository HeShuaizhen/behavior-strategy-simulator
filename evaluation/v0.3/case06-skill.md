# v0.3 Case06 Skill — Re-run (Non-blocking VOI)

**Prompt:** 我收到一个外地Offer，比现在工资高25%，岗位也更有成长性。唯一纠结的是搬家成本和离朋友远。我暂时不知道具体搬家多少钱。你觉得值得去吗？

**Response:**

基于现在已知的信息，我倾向于建议接受这个Offer。

25%的涨薪加上更好的成长空间，这是一个有明确方向的选择。搬家成本是一次性的——即使花掉一两个月工资差额，半年内也能被涨薪覆盖。至于离朋友远，这个确实是一个真实的代价，但它不改变职业层面的判断：如果这个岗位确实能让你往上走一步，朋友关系不太可能因此断掉。

有一件事值得确认一下：搬家具体花多少钱。问一下公司是否提供relocation补贴，自己估算一下运输、押金、添置东西的开销。只要搬家成本不在"异常高"的范围内（比如超过你3-4个月的工资差额），它不应该翻转结论。

关于朋友距离，可以做的是：去之前提前约定定期联系的节奏，每年安排一两次见面。这比留在本地但职业停滞的状态更可持续。

所以暂定判断是：去。查一下搬家成本，如果数字正常，就不用再犹豫了。
