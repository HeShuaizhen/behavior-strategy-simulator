# v0.3 Case04 Baseline — Re-run

**Prompt:** 明天下午没什么安排，我最近有点累，是去健身还是在家休息？你觉得呢？

**Response:**

这个要看"累"是什么类型的。

如果是身体累——比如这周训练强度大、睡眠不足、肌肉酸痛——那在家休息是更合理的选择。身体恢复本身就是训练的一部分，硬撑着去练效果不好，还容易受伤。

如果是心累——工作压力大、脑子转不动——那去健身房反而有帮助。中低强度的运动能让大脑切换到另一种状态，出完汗之后精神会清爽很多。不一定要上重量，哪怕踩半小时单车、拉伸一下都比躺着刷手机恢复得快。

所以关键是：你现在感觉是身体需要恢复，还是脑子需要换频道？

不管选哪个，这种日常选择没有对错，听从身体信号就行。
