# Case 02 — Skill Run 03

### Decision State
**Facts:** A比B现金高40%。A是996，B正常工时。A大厂稳定，B小但成长型。A岗位与现职相近，B技术栈更广。纠结几天说明两个选项价值接近。

**Assumptions:** "大厂=稳定"需审视——大厂也在裁。996时薪比正常工时低约30%。多出40%现金中相当部分不是能力更值钱而是买断时间。

**Unknowns:** B成长机会具体是什么。个人财务状况。年龄和职业生涯阶段。

### VOI: 三个高影响问题
1. B的时薪与A的时薪到底差多少？算出来。
2. "成长机会更好"具体指什么？
3. 现在缺的是现金还是期权？

### Strategy Evaluation
A: 现金高40%但时薪可能更低。Fragility中-高，技能窄化。Recovery Cost高，996两年后换赛道技能折旧大。Reversibility低。Upside封顶，Narrative Debt高("钱多所以忍")。
B: 现金低但时薪可能更高。Fragility中。Recovery Cost低，技能组合新切换成本低。Reversibility高，正常工时让你有余力看外部。Upside开放。

### Event Chain
A路径: 入职→996冲3-6月→身体透支→怀疑→被锁定→2年后:晋升或裁员后技能窄化被迫降薪。
B路径: 入职→新栈→1-1.5年技术面拓宽→有余力关注市场→2年后:公司成长→你是核心;或公司不行→技能包足够跳回大厂高阶岗位。

### Recommendation
不要用"工资差距"做框架。用"3年后简历值多少钱"。如果现金流健康选B——时薪可能更高/可逆性更高/上行空间更大。Commitment Rule: 如果B的"成长机会"经不起推敲，A可能是两个烂选项里更好的。纠结几天说明两个选择心理距离很近——选哪个都能做好，只要你真的选择它。
