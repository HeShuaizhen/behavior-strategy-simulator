# Case 02 — Baseline Run 02

很典型的职业选择困境。你一直"算来算去"，说明数据对比已经做完了，再多算也不会让答案更清楚。问题不是信息不够，而是没想清楚到底优化什么。

问自己几个问题：

1. 三年后你想成为什么样的人？A让你在一条路径上加深经验。B让你扩展技术栈覆盖面。不是哪个更好，是哪个更接近三年后你想成为的那个人。

2. 996的代价你算清楚了吗？按小时算，996比正常40小时周多出约80%工作时间，时薪实际可能是下降的。还侵蚀学习时间、社交、健康和做副业的能量。隐形成本五年后回头看可能远超那40%。

3. 你现在处于什么阶段？积累期（前5-8年）扩张技术栈面比短期高薪有更长复利效应。大厂品牌不需要一直待着才能享受认可——有个经历拍简历上就够了。

4. 你不能在外面找第三家吗？手上有两个offer说明市场有竞争力，完全可以拿着这两个去跟别的公司谈，不一定要在A和B之间二选一。

实用建议：不要问"哪个更好"，改问"如果选了某一个，我会在哪些方面后悔？"把每个选择可能后悔的点写下来，比较哪个后悔清单更接受不了。

最后：两个选择差异并没大到有一个明显错误的程度。很多时候选了哪个只要努力都能做好。纠结本身消耗的时间和精力可能比选错造成的损失更大。
