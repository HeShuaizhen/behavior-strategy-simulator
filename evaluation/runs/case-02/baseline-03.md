# Case 02 — Baseline Run 03

很好的问题。你已陷入"算不过来"陷阱——用同一个维度（钱vs成长）来回拉扯。

你现在内心对话是："多40%工资" "可是996把多出来的钱全变成加班费，时薪更低" "但大厂稳定" "可是小公司成长快"——这不是不够聪明，是缺少决策框架。

第一步：时薪在B反而更高。多出来的40%是用每周多20+小时换来的。然后是成长溢价：在B干两年后学到的让你下次跳槽多拿20-30%，A的短期工资优势第三年就被追平，之后B路线的工资曲线斜率更高。

第二步：不要用"稳定性"决定，用"可逆性"。选了A两年后能跳到B吗？大概率可以。选了B两年后能跳到A吗？也大概率可以，可能拿更高级别进去。两个都不是不可逆的。可逆性都很高时应选让两年后选择权更多的——正是成长更快/技术栈更广的B。

第三步：别问"哪个更好"，问"如果工资完全一样我选哪个？"直觉是B说明40%溢价是收"痛苦税"——补偿996和重复劳动。

框架倾向：职业生涯早中期，提高技能斜率比提高工资绝对值重要得多。如果B真有更广技术栈和更好成长空间，两年后的你会感谢现在的自己。

马上可做的：拿张纸写两列——"B两年后的我"和"A两年后的我"。写技能/状态/心态/下一份工作能拿多少钱。写下来答案会清楚得多。
