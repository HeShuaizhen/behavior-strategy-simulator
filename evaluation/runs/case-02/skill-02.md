# Case 02 — Skill Run 02

### 1. 会计纠正
996≈每周72h，正常≈40h。A高40%但工时多80%，时薪比B低。多出来的32h/周是不能陪家人/锻炼/副业/学习的时间。把总包换成时薪再感受。

### 2. VOI问题
问题一：职业生涯什么阶段？<5年选B理由强很多。>10年+有家庭压力A有道理但996强度能撑多久。
问题二：B公司钱还能烧多久？融资到哪轮/runway多长/过去两年人员净增还是净减。

### 3. 策略评估
**A:** 直接收益多40%现金。Fragility高——单一技能栈积累，抗裁员能力随时间下降。Exposure窄。Recovery Cost中偏高——两年后跳出来技能同质化严重。Reversibility中——大厂跳小厂容易但反向不一定，996挤压面试精力。Asymmetry不理想——赚了现金但付出不可回收时间，没有杠杆只有工资。
Event Chain: 6个月适应节奏没时间想别的→18个月身体有信号想跳没精力准备→3年没升到带人岗变成贵且可替代的资深执行者。

**B:** 直接收益更广技术栈+可控时间。Fragility中(取决于财务状况)。Exposure宽——接触更多东西未来选择权多。Recovery Cost低——一年后发现不行跳回大厂成本不高且多了技能。Reversibility高——小厂经历+更广技术栈比单一大厂经历更多出路。Asymmetry好——上有杠杆(公司成不成技能都带得走)。
Event Chain: 6个月学新东西有掌控感下班后还有精力→18个月技术栈拓宽简历有实质性新东西→3年好情况收益巨大/坏情况技能升级回市场更灵活。

### 4. 反直觉判断线索
已经想了几天还选不出来本身就是信号。真想去996赚两年钱会直接去因为逻辑干净："累但钱多干两年走人"。反复纠结意味想选B但不敢——因为B看起来"不安全"而A看起来"对的选项"。在试图用理性说服自己选A但身体不认同。

### 5. 建议
信息不够→找B的CTO聊"接下来一年做什么项目能碰到什么技术"。信息够了但纠结→选B。因为时薪实际B不低于A，成长是复利，错了代价远小于A错了代价，纠结本身就是抗拒A。什么情况选A正确：有具体紧迫财务目标且明确"就一年后必须走"。
