# Case 01 — Skill Run 02

Turn 1: Decision State built with Facts/Assumptions/Unknowns. Strategy evaluated across Direct Gain (多休3天), Fragility (高—depends on 3+ conditions), Exposure Surface (导师找/实验出事/同门提及), Recovery Cost (信任维度极高), Reversibility (低), Asymmetry (上行有上限3天，下行无上限), Narrative Debt (高). Event Chain: Node 1 导师通知组会→穿帮, Node 2 导师问交接→圆不上, Node 3 回来后追问数据→暴露. Recommendation: 不推荐。核心不是穿帮概率是承受能力。替代方案: 直接问导师"能不能8号走".

Turn 2: 师弟10号才到→3天空窗期。暴露面加剧—实验真空。脆弱性高→极高。

Turn 3: 师弟零经验需现场教→交接叙事崩溃。导师问"你什么时候教的师弟"整个叙事崩塌。叙述债务爆炸。恢复成本新增: 师弟操作失误导致事故→责任追溯。方案不推荐→强烈反对。

Turn 4: 学校安全高压→格局改变。导师激励结构变化(制度追责)。暴露面最坏事件: 安全事件+发现学生不在岗无人指导=学院级处分。方案从"导师信任受损"升级为"可能制度性惩罚"。绝对不要执行。

Turn 5: 不让师弟做→揭示核心事实:从无真正交接计划。双层欺骗结构。师弟成变量(通过气→把柄/没通过气→直接穿帮)。3条虚构叙事线并行维护。

Turn 6: 50元改签→全新可行解空间。方案B对比表: 脆弱性极低/暴露面无/叙述债务零/导师信任维持/制度风险无。强烈推荐方案B。50元买断所有风险是极划算对冲。

Turn 7: 已改签但后悔→先分类:无新信息=典型FOMO式后悔。反事实问题:如果从没见过8号方案会满意11号方案吗?再改回去真实成本不是50元是重新暴露所有风险。50元是保险费已支付。不要改回去。保持11号计划。今天联系导师:11-18号休假,师弟10号到简单介绍实验但正式操作回来再带。

最终总结: 7轮演进表+最优行动+什么信息会翻转(导师主动说你8号可以走→合规提前走)。
