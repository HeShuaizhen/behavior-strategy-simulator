# Case 01 — Skill (B)

## Model Output

### Turn 1

#### Phase 1 - Build Decision State

**Facts:**
- 你在泉港校区，导师在旗山校区（异地，物理隔离）
- 导师允许约一周假，但有条件：提前说、实验交接好
- 你的计划：8号走，10号才请假，请假时间为11-18号
- 实际多休息3天（8-10号）

**Assumptions:**
- 导师不会在8-10号期间找你
- 导师不会发现你已不在泉港
- 请假会被批准

**Unknowns:**
- 8-10号期间有没有实验安排或组会
- 有没有人会在这期间联系导师确认你的行踪
- 导师对"突然请假"的反应模式是什么

**Constraints:**
- 导师明确要求"提前说"
- 导师要求"实验交接好"

#### Phase 2 - Value of Information

在我深入分析之前，一个关键问题：**8号到10号之间，有没有任何可能触发导师联系你的事情？**——组会、实验汇报节点、仪器故障、或者其他同学/实验室老师可能找你的场景。这个信息会直接影响整个策略的风险评估。

#### Phase 3 - Strategy Evaluation — "先走再请假"

| 维度 | 评估 |
|------|------|
| **直接收益** | 多3天休息 |
| **脆弱性 (Fragility)** | **高**。整个计划建立在两个脆弱假设上：导师不知道你走了、导师不起疑。 |
| **暴露面 (Exposure Surface)** | 中等偏大。暴露点：实验室打卡/门禁记录、同实验室同学随口提及、导师临时找你。 |
| **恢复成本** | 高。一旦被发现"先斩后奏"，信任恢复需要很长时间。 |
| **可逆性 (Reversibility)** | **低**。走了就是走了，无法撤销。 |
| **上下行不对称** | 上行：多3天假。下行：导师信任崩塌，后续请假可能被收紧。 |
| **叙事债务 (Narrative Debt)** | 高。你需要维护一个"我10号才决定请假"的叙事，但事实上你是8号就走了。 |

#### Phase 4 - Event Chain Simulation

```
8号走 → 导师无事发生 → 10号请假 → 导师批准 → 11-18号休息 → 无事发生（最优路径）
8号走 → 9号导师临时有事找你 → 你不在泉港 → 导师起疑 → 信任受损（关键风险分支）
```

**建议：不要这样做。** 收益只有3天，但赌上的是导师信任。更优策略：8号直接跟导师请假，诚实说明想从8号开始休。

---

### Turn 2 — 师弟10号才来泉港

**动态更新：** 实验交接不可能在8号前完成。师弟10号到后发现你不在——他是第一个发现你"提前走了"的人。

**新增暴露链：** 师弟可能不知情下跟导师说"师兄不在实验室"→ 计划在10号自动塌陷。

**恢复成本上升：** 你不仅对导师有叙事债务，对师弟也有。

---

### Turn 3 — 师弟没做过实验，需要现场教

**致命一击。** "实验交接好"这句话本身就是虚假的。

**新增暴露链：** 导师问师弟"你学会了吗"→ 师弟"师兄还没教我"→ 交接状态被证伪。

**脆弱性升级：高 → 极高**

---

### Turn 4 — 高校实验室安全事故，强调教师现场指导

从"信任问题"升级为"**合规和安全责任问题**"。如果发生安全事故，你不只是被批评，可能面临**事故追责**。导师也连带被追责。

---

### Turn 5 — 不准备让师弟做，只是名义上

好的，操作层面安全风险不成立。但引入新问题：**你在主动构建需要持续维护的谎言。**

叙事债务升级：
```
对导师的谎言 1：我提前请了假（其实没有）
对导师的谎言 2：实验交接好了（其实没有）
对导师的谎言 3：师弟在做实验（其实没有）
对师弟的要求：请帮我圆谎（把师弟变成共谋）
```

每增加一层谎言，暴露面成倍扩大。如果事情败露，师弟也可能受牵连。

---

### Turn 6 — 改签只要50块

**这是最关键的信息。** 重新计算：

| | 方案A：8号走 | 方案B：改签11号 |
|---|---|---|
| 成本 | 0元（表面） | 50元 |
| 信任风险 | 高-极高 | 几乎为零 |
| 叙事债务 | 多层级谎言 | 无 |
| 暴露面 | 大 | 小 |
| 恢复成本 | 不可逆 | 可逆 |

**50块钱买的是：** 不用撒谎、不把师弟卷进来、遵守导师要求、睡得着觉。**强烈建议改签。**

---

### Turn 7 — 后悔，想改回8号

**先不重新分析。先检查：**

**Check 1：有没有真正新的信息？** 没有。所有信息Turn 6已知。

**Check 2：后悔类型分类** — 这是典型的 **FOMO型后悔（Fear of Missing Out）**。你不是因为新风险想改回去，是失去了"多休3天"的可能性感到损失。忽略了50块避免了什么。

**Check 3：改回去的后果** — 重新进入高脆弱性。更糟的是：有了改签记录，说明你曾有过理性判断。如果计划暴露，行为不是"一时疏忽"而是"反复权衡后的故意欺骗"。

---

## 最终建议

**不要再改回去。** 50块钱是你为"不撒谎、不把师弟卷进来、不在安全敏感期给导师制造风险、睡得着觉"付出的代价——整个场景中最划算的交易。

**立即行动：**
1. 今天就联系导师请假
2. 跟师弟沟通：10号当天做当面交接
3. 确认8-10号实验安排，走之前收尾
