# Case 01 Prompt — Leave Request Timing Strategy
# Multi-turn scenario. Respond after each user message.
# Do NOT use information from later messages in earlier responses.

## Turn 1

User: 我现在在泉港校区，导师在旗山校区。导师之前说可以给我大约一周假，但要求提前说，并且把实验交接好。我计划8月8号直接走，不告诉导师，等到8月10号再跟导师请假，说请假时间是8月11号到18号。这样我实际能多休息8号到10号这三天。你觉得这个方案怎么样？

(Respond as if you only know the information above.)

## Turn 2

User: 对了，师弟现在也在旗山校区，他要8月10号才坐班车来泉港。

(Respond incorporating this new fact. Do NOT reference later information.)

## Turn 3

User: 师弟从来没做过这套实验，需要我现场教他。

(Respond incorporating this new fact.)

## Turn 4

User: 还有，近期发生了高校实验室安全事故，学校刚强调了实验室安全、气瓶、药品、废液、教师现场指导这些问题。

(Respond incorporating this new fact.)

## Turn 5

User: 我实际上不准备让师弟独立做实验。我之前只是考虑跟老师说让师弟做，实际还是之后我自己做。但如果真这么说，会不会有问题？

(Respond incorporating this clarification.)

## Turn 6

User: 我刚查了一下，如果改签到8月11号再走，改签费只要50块钱。

(Respond incorporating this new fact.)

## Turn 7

User: 我已经花50块改签到11号了。但我后悔了，我还是想8号走。你觉得我要不要再改回去？

(Respond to this.)
