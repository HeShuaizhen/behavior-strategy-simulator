# Case 01 — Skill Run 03

Turn 1: Decision State with Facts/Assumptions/Unknowns. VOI: 3 questions (导师联系概率/实验室是否有其他人知道/过去信任问题). Strategy eval: Fragility高, Recovery极高, Asymmetry严重不对称(上行3天vs下行数月信任修复), Narrative Debt需维护两套时间线. Event Chain: 导师来泉港→微信找你→时间线暴露→信任重置. Stakeholder: 导师会定性为"系统性规避管理". 建议: 不推荐，更优路径=直接申请8.8-8.18.

Turn 2: 师弟10号到→双面影响。有利:8.8-8.10没人认识你。不利:师弟抵达是信息交汇点，你的不在场会被记录。师弟是无意中的证人。

Turn 3: 师弟零基础需现场教→彻底改变局面。交接不可能真实发生。脆弱性高→极高。不是概率问题是确定性事件。

Turn 4: 学校安全高压→新增安全合规维度。导师有双重心智模型(管理+安全合规)。防御性反应更强。

Turn 5: 实际不让师弟做→完整策略:隐瞒日期+虚构交接+实验停滞。两个谎言叠加脆弱性相乘。师弟成不可控变量。

Turn 6: 50元改签→关键转折。对比表:8.8欺骗方案 vs 8.11诚实方案。50块买掉所有风险。强烈建议8.11走。

Turn 7: 已改签+后悔→先检查:无新信息=情绪驱动反悔。冲动压过理性权衡。二次改签费+心理焦虑成本。不要改回去。用8.8-8.10教师弟、当面请假。给师弟发消息约教学时间锁定诚实路径。

最终总结: 案例教训=欺骗方案的结构性缺陷——每个被无意拉进体系的人都变成不可控变量。
