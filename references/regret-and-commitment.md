# Regret and Commitment

How to handle "I've changed my mind" — without endless decision cycling.

---

## Regret Classification

When a user expresses regret after a decision, first classify **what kind** of regret:

| Type | Description | Reopen? |
|------|-------------|---------|
| **New Information** | A genuinely new fact has emerged that wasn't known at decision time. | **Yes** — re-evaluate. |
| **Counterfactual Regret** | "What if I had chosen differently?" — imagining a better unchosen path without evidence it would have been better. | **No** — this is emotional, not informational. |
| **FOMO (Fear of Missing Out)** | Anxiety that another option might have been better, without specific evidence. | **No** — unless concrete new information exists. |
| **Loss of Autonomy** | Discomfort from feeling locked in, regardless of whether the decision was good. | **Maybe** — address the autonomy need, not necessarily the decision itself. |
| **Decision Reopening** | Habitual second-guessing — a pattern of reopening decisions. | **No** — this is a pattern to name, not a reason to re-decide. |
| **Sunk-Cost Discomfort** | "I've already invested so much in this path." | **No** — past cost doesn't justify continuing or stopping. Evaluate forward-looking only. |
| **Fear of Missed Upside** | Worry that the unchosen path had more upside. | **No** — unless there's new evidence the upside is real and accessible. |

---

## The Reopening Gate

Before re-evaluating any decided matter, ask:

1. **Is there genuinely new information?**
   - If yes → re-evaluate.
   - If no → go to step 2.

2. **Which regret type is this?**
   - Classify using the table above.

3. **Would re-deciding actually change anything?**
   - If the same constraints and facts still hold, a new round of analysis will reach the same conclusion. Reopening just burns mental energy.

4. **Is there a pattern?**
   - If the user repeatedly reopens decisions, name the pattern without judgment.

## Commitment Rules

After a significant decision is made, establish a **Commitment Rule**:

> This decision will not be reopened unless [specific condition] occurs.

### Example Commitment Rules

- "Unless the rebooking cost drops below X, we stay with this plan."
- "Unless a new stakeholder enters with decision authority, this is settled."
- "Unless the deadline changes by more than 2 days."
- "Unless [key assumption] is proven false."

### Why Commitment Rules Matter

They prevent:
- Emotional oscillation between options
- Decision fatigue from re-litigating settled questions
- Wasting analysis on counterfactuals that can't be verified

They also give the user permission to **stop thinking about it**.

---

## When to Hold vs When to Fold

**Hold** (stick with the decision) when:
- No new information has emerged
- The regret is primarily emotional/counterfactual
- The original reasoning still holds
- Reopening costs (time, stress, indecision) exceed expected benefit

**Fold** (reopen) when:
- A concrete new fact changes the calculus
- A key assumption has been proven wrong
- The cost or feasibility of the chosen path has materially changed
- A better option has become genuinely available
