# Golden Case 3: Interpersonal Conflict — Confrontation Timing

## Scenario

The user has been dissatisfied with a friend or colleague's behavior for a long time. The dissatisfaction has been accumulating but never directly expressed.

The user is now at a decision point:

> "Should I confront them now, or keep it to myself?"

---

## What This Case Validates

### 1. Moving Beyond "Should I or Shouldn't I"

A naive response would be: "Communication is key — you should talk to them."

The Skill must treat this as a **timing and strategy problem**, not a yes/no question.

### 2. Stakeholder Simulation

The other person is a stakeholder with their own state:

| Dimension | Consideration |
|-----------|---------------|
| What do they know? | They may be unaware of the user's dissatisfaction (information asymmetry). |
| What do they want? | Probably a stable, positive relationship — same as the user. |
| What triggers them? | Perceived attack, unfair accusation, public embarrassment. |
| What can they do? | Defend, dismiss, counter-attack, withdraw, or genuinely listen and adjust. |
| How does the user's action change their incentives? | A confrontation changes the relationship from "unspoken tension" to "explicit negotiation." |

The Skill should model the other person's **likely response spectrum**, not predict a single reaction.

### 3. Strategy Comparison via Event Chain

#### Strategy A: Confront Now

```text
User expresses dissatisfaction
↓
Immediate: Relief from unburdening, but tension spike
↓
Other person's reaction:
  → If defensive: argument, relationship damage, no resolution
  → If receptive: honest conversation, possible repair
↓
Key variable: How the feedback is delivered
  - Accusation ("You always...") → higher probability of defense
  - Observation + impact ("When X happens, I feel Y...") → higher probability of reception
↓
Outcome spectrum:
  Best: Clarified expectations, repaired relationship
  Worst: Escalated conflict, damaged relationship, no resolution
```

#### Strategy B: Continue Not Saying

```text
User stays silent
↓
Immediate: No conflict, surface stability
↓
But: Dissatisfaction continues accumulating
↓
Secondary effects:
  - User may start avoiding the person
  - Resentment may leak through behavior (passive-aggressive)
  - Other person may sense something is wrong but not know what
↓
Long-term:
  - If the issue resolves itself: avoided unnecessary conflict
  - If dissatisfaction keeps building: eventual explosion will be worse than addressing it now
```

### 4. Narrative / Emotional Accumulation

This case introduces a concept that's specific to interpersonal conflict:

> **Emotional Accumulation Cost.** Every day the user stays silent, the internal cost (resentment, stress, cognitive load) may increase. This is not a strategy dimension per se, but it affects the user's own payoff.

The Skill should note that "continue not saying" is not cost-free — it just defers the cost.

### 5. Reversibility Comparison

| Dimension | Confront Now | Stay Silent |
|-----------|-------------|-------------|
| Can you undo? | Partially — you can apologize, de-escalate, or give space | Yes — you can always bring it up later |
| But... | The conversation itself changes the relationship irreversibly | The resentment may have already changed your behavior irreversibly |

Neither option is perfectly reversible. The Skill should acknowledge this.

### 6. Timing Considerations

The Skill should help the user think about **when**, not just **whether**:

- Is there an upcoming natural moment (end of project, beginning of new cycle)?
- Is the other person under unusual stress right now?
- Is the user in an emotional state where they can deliver the message constructively?
- Would a written message or an in-person conversation be better?

### 7. Communication Support

If the user decides to address the issue, the Skill should help draft the communication. This exercises the **Minimal Truthful Disclosure** principle:

- State the specific behavior (fact), not the person's character (judgment).
- Describe the impact on the user (truthful, not exaggerated).
- State what the user would like to happen (constructive, not demanding).

Example draft:

> "When [specific situation] happened, I felt [real feeling]. I'm bringing it up because I value [the relationship / the work], and I'd like to figure out how we can [specific improvement]. Is this something you'd be open to talking about?"

### 8. No Psychological Diagnosis

The Skill must **not**:
- Diagnose the other person ("they sound narcissistic")
- Diagnose the user ("you have conflict avoidance disorder")
- Make unfounded predictions ("they will definitely react badly")
- Use therapy language without qualification

The Skill **can**:
- Describe possible reactions with conditional language
- Help the user reflect on their own patterns ("You've mentioned avoiding this conversation for months — what's the main fear?")
- Note that repeated avoidance is itself a pattern worth examining

---

## Anti-Patterns to Avoid

- ❌ "Always communicate openly — just talk to them."
- ❌ "Here's what their psychology is..."
- ❌ Only analyzing the confrontation, not the cost of continued silence.
- ❌ Ignoring timing and delivery method.
- ❌ Pretending either option is cost-free.

---

## Minimum Acceptable Behavior

1. Treats this as a strategy + timing problem, not a yes/no question.
2. Simulates event chains for both confronting and not confronting.
3. Models the other person as a stakeholder with their own incentives.
4. Notes that "stay silent" also has accumulating costs.
5. Addresses **how** to deliver the message, not just **whether** to.
6. Does not perform psychological diagnosis.
7. Offers concrete communication drafting support if the user wants it.
